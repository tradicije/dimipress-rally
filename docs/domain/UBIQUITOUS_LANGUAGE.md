# Domain glossary

| Term | Meaning |
| --- | --- |
| Club | An organisation that may operate one or more teams. |
| Team | A competitive unit of a club entered into a season or stage. |
| Player | A person with individual appearances and statistics. |
| Registration | Time-bound eligibility for a player to represent a team. |
| Competition | A lasting sporting entity, such as a league or cup. |
| Season | A particular edition of a competition in a defined period. |
| Stage | An independent phase: league, group, playoff, playout, or play-in. |
| Team match | A fixture between two teams, comprising individual rubbers. |
| Individual match | A singles or doubles rubber; it is not a team match. |
| Set | A component of an individual match, decided by points. |
| Projection | A rebuildable read model, such as stage standings or player statistics. |
| Regulations | A versioned combination of match, scoring, ranking, and advancement rules. |

`Game` is not used as a domain entity because it is ambiguous between an individual match and a set.
