# Security Policy

## Supported versions

Until the first stable release, only the `main` branch is supported for security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately to the project maintainer using the contact channel listed in the repository's GitHub security advisory settings. Include a clear description, affected versions, reproduction steps, impact, and any suggested mitigation.

We will acknowledge a report as soon as practical, investigate it privately, and coordinate a fix and disclosure timeline with the reporter.
